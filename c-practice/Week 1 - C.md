- TO compile and run in terminal
```
gcc -Wall "name of the .c file" -o "name of the file" && ./"name of the file"
```
```
ex. gcc -Wall hello.c -o hello && ./hello
```

- Every program follows the same loop:
```
write - compile - test - git add . - git commit -m "what you built" - git push -u origin main
```
